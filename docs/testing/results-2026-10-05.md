Pengujian integrasi memakai project Compose `gudang-kita-brief-test`; container dan volume sementara dibersihkan setelah tes. Pemeriksaan HTTP read-only menggunakan sesi akun pada database aktif serta instalasi bersih; contoh transaksi dibuat terpisah melalui service.

Bukti screenshot tersedia pada [indeks gambar](screenshots/README.md). Video demo alur tiga peran dan latihan presentasi masih perlu disiapkan oleh peserta. Pemeriksaan instalasi bersih dilakukan pada salinan Docker terpisah. Seluruh container dan volume tes sudah dibersihkan; volume database aplikasi aktif dipertahankan.

Rekonsiliasi ledger menjaga `stocks` dan order lama tetap sama. Movement berlabel `LEGACY-BASE-*` adalah titik penyesuaian bersih untuk data sebelum ledger lengkap tersedia; ia tidak membuktikan rincian setiap transaksi historis. Counter `stock_in/stock_out` lama belum dapat dijabarkan seluruhnya menjadi Receipt/Issue individual.

Uji HTTP terbaru dapat diulang dengan `docker compose -p gudang-acceptance -f docker-compose.acceptance.yml up -d --build --wait`, `python3 tests/http_acceptance.py`, lalu `docker compose -p gudang-acceptance -f docker-compose.acceptance.yml down -v`. Jalankan hanya pada stack tes dengan port 18081 karena skenario CRUD mengubah database sementara.
